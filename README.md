# 👟 Ficha de Zapatillas (Product Card)

Este repositorio contiene el código de una **Ficha de Producto** interactiva y maquetada desde cero. Es un componente clásico de comercio electrónico (*e-commerce*) diseñado para poner en práctica la maquetación visual, el uso de etiquetas semánticas y el diseño responsive.

## 🎨 Características del Proyecto

* **Estructura Semántica:** Uso de etiquetas HTML5 adecuadas (`<article>`, `<section>`, `<figure>`, etc.) para estructurar la información del producto de forma accesible.
* **Diseño Visual:** Maquetación limpia usando CSS (Flexbox / Grid) para alinear la imagen del calzado, la descripción, el selector de tallas y el botón de compra.
* **Interactividad Básica:** Estilos para los estados de los elementos interactivos (efectos `:hover` en botones y opciones de talla).
